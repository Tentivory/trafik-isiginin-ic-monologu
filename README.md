# Trafik Isiginin Ic Monologu

Bu depo, bir trafik isiginin gece yarisi kendi kendine konusmasini **bilimsel ciddiyetle** arsivler.

Proje bir oyun degildir. Proje bir sanat eseri de degildir. Proje, kavsaklarin sessiz emekcisinin resmi sozlusudur.

## Neden?

Cunku kirmizi yanan bir isik yalnizdir. Yesil yanan bir isik kalabaliktadir. Sari yanan bir isik ise varolussal krizdedir.

Biz bu krizleri kayda aldik. Siz de izleyebilirsiniz.

## Kurulum

Python 3 yeter. Baska hicbir sey istemiyoruz. Isik da istemiyor.

```bash
python3 isik.py
```

Durdurmak icin `Ctrl+C`. Isik sizi yargilamayacak. Belki biraz uzulecek.

## Ozellikler

- Gercek zamanli (gercek olmayan) monolog
- Uc resmi duygu hali: kirmizi, sari, yesil
- Durunca damga basar
- Calisir. Gercekten calisir. Inanmiyorsaniz calistirin.
